# 🎬 AI Video for Kids: skill para criar vídeos infantis com IA

**Transforme uma ideia de uma linha em um vídeo infantil completo, seguro e pronto para publicar no YouTube Shorts, TikTok ou Reels.**

> "Faz um vídeo ensinando as cores para crianças de 2 anos"
> → roteiro, personagem, storyboard cena a cena, prompts prontos para Midjourney/ChatGPT/Kling/Runway, narração, legendas e kit de publicação.

Uma *agent skill* para o Claude (e outros agentes compatíveis) feita para criadores de canais infantis, professores e pais.

---

## ✨ O que a skill faz

- 📝 **Roteiro original** (música, historinha, vídeo educativo ou de dormir) no ritmo certo para cada idade: 2-3, 4-5 ou 6-8 anos
- 🐶 **Personagem consistente**: uma "bíblia" de estilo que mantém o personagem igual em todas as cenas
- 🎞️ **Storyboard cena a cena** com duração, câmera, ação e narração
- 🎨 **Prompts prontos para colar** em Midjourney, ChatGPT/DALL-E, Gemini, Leonardo, Kling, Runway, Hailuo, Veo
- 📱 **Formato certo para cada plataforma**: 9:16 para Shorts/TikTok/Reels, 16:9 para YouTube e sala de aula
- 🛡️ **Segurança infantil embutida**: nada assustador, sem personagens protegidos, sem chamadas comerciais para crianças
- 🌎 Funciona em **português, inglês e espanhol**

## 🆓 Versão gratuita (este repositório)

A pasta [`ai-video-for-kids-lite`](./ai-video-for-kids-lite) traz a versão **Lite**: o fluxo de criação de roteiro, personagem e storyboard. Ótima para experimentar.

Na pasta [`exemplos`](./exemplos) há storyboards completos em português e em inglês para você ver o resultado.

### Como instalar a versão Lite

1. Baixe este repositório (botão verde **Code → Download ZIP**)
2. Copie a pasta `ai-video-for-kids-lite` para a pasta de skills do seu agente (no Claude, pela área de **Skills** nas configurações)
3. Peça: *"Crie um vídeo infantil curto sobre os animais da fazenda para crianças de 4 anos"*

## 🇺🇸 English

**AI Video for Kids** is an agent skill that turns a one-line idea into a complete, safe, age-appropriate children's video package: original script or song, consistent characters, scene-by-scene storyboard, ready-to-paste prompts for image and video AI tools, narration, subtitles and a publishing kit, for YouTube Shorts, TikTok, Reels or classic 16:9 YouTube. Ages 2-8, any language.

This repository contains the free **Lite** version (script, character and storyboard workflow). The full version adds an automatic validator, TTS-ready narration, `.srt` subtitles, a publishing kit and automatic MP4 assembly with ffmpeg.
